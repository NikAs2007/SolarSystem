# SolarSystem

Простая симуляция гравитации между планетами на C++ с использованием SFML.

## Возможности

- Симуляция гравитационного взаимодействия между планетами
- Визуализация движения планет в реальном времени

## Требования

- Компилятор с поддержкой C++17
- CMake 3.5 или выше

## Сборка

    ```
    mkdir build
    cd build
    cmake ..
    cmake --build .
    ```
    
Исполняемый файл появится в папке build/

## Управление

- Закрыть окно — нажмите крестик или Esc
